# 🏥 Medicare - Hospital Management System (Frontend)

A modern, responsive frontend for the Medicare system built using **React, Vite, and Tailwind CSS**, designed with a focus on **clean UI, scalability, and role-based user experience**.

---

## 🚀 Features

### 👤 User Features

* Register, Login, Email Verification
* Book & manage appointments
* Online payment (Razorpay)
* Track appointment status
* Download appointment slip
* Real-time notifications

---

### 👨‍⚕️ Doctor Dashboard

* View & manage appointments
* Approve/reject appointment requests
* Patient consultation management
* Profile creation & updates

---

### 🛠 Admin Dashboard

* Manage doctors & departments
* View system analytics & reports
* Payment tracking
* Real-time notifications

---

## 🧠 Core Concepts

* Role-Based Routing (Admin / Doctor / User)
* Custom Hooks for logic abstraction
* Context API for global state
* Service layer for API communication
* Reusable component architecture
